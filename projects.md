A curated selection of computational mathematics, scientific machine learning, and engineering projects. The linked repositories contain implementation details and, where available, experiments and reproducibility notes.

## Numerical modeling

- **[FEM cylinder flow](https://github.com/AdebanjiAdelowo/fem-cylinder-flow)** — benchmark incompressible flow simulation.
- **[Darcy inverse problem](https://github.com/AdebanjiAdelowo/darcy-inverse-problem)** — finite-element inverse coefficient reconstruction.
- **[FEM topology optimization](https://github.com/AdebanjiAdelowo/fem-topology-optimization)** — constrained structural optimization.

## Inverse problems and dynamical systems

- **[Lorenz-96 data assimilation](https://github.com/AdebanjiAdelowo/lorenz96-data-assimilation)** — state estimation in chaotic systems.
- **[Photoacoustic reconstruction](https://github.com/AdebanjiAdelowo/photoacoustic-reconstruction)** — image reconstruction from indirect measurements.

## Scientific machine learning

- **[Neural surrogate Burgers](https://github.com/AdebanjiAdelowo/neural-surrogate-burgers)** — reduced-order modeling and neural surrogates.
- **[Navier–Stokes 2D](https://github.com/AdebanjiAdelowo/navier-stokes-2d)** — fluid simulation and reduced-order model evaluation.

For detailed project-readiness assessments and limitations, see the [scientific audit](https://github.com/AdebanjiAdelowo/selected-projects-scientific-audit). Project inclusion here does not imply every experiment is complete.
